# ผลตรวจและปรับปรุงโปรเจกต์ — 6 กันยายน 2026

ตรวจหน้าบ้าน หลังบ้าน MySQL จริง และบริการอ่านภาพ พร้อมลบโค้ดที่ไม่ใช้และเพิ่มส่วนที่จำเป็นสำหรับความพร้อมใช้งาน

## เก็บกวาดแล้ว

- ลบ `MemberService.billRepository` ที่ไม่ถูกอ่าน โดยยังเก็บ `BillEntity` ที่ใช้ใน transaction
- ลบ interface `MeterReading` และ `uploadCroppedImage()` ฝั่งเว็บที่ไม่มีผู้เรียก
- แก้ README ให้ตรงกับโครงสร้างปัจจุบันและ browser build ที่ไม่ได้เปิด SSR/prerender
- ไม่ลบ migration, โมเดล, รูป, ชุดทดสอบ หรือ dependency ของ framework ที่ยังจำเป็น

## เพิ่มแล้ว

- จำกัดรูป 10 MB ต่อไฟล์, 32 MB ต่อคำขอ, 30 รูปต่อ batch และ 40 ล้านพิกเซล พร้อมตรวจข้อมูลภาพจริงทั้ง NestJS และ Python
- จำกัดการล็อกอิน 20 ครั้งต่อนาทีต่อ IP พร้อม `Retry-After`
- ตรวจชนิด ช่วง และขนาดข้อมูลใน DTO โดยยังรองรับ numeric string และฟิลด์เก่าที่ client ใช้อยู่
- ป้องกันการส่ง `admin_role` แทรกเพื่อยกระดับสิทธิ์ตอนสร้างบัญชี
- เพิ่ม CORS แบบระบุ origin, ปิด Swagger ได้, รองรับ reverse proxy/HTTPS และ API URL runtime สำหรับหน้าเว็บ
- เพิ่ม `/health` และ `/health/ready` ตรวจ API, MySQL และ AI แยกกัน
- เพิ่มคำสั่งสำรอง/กู้คืนพร้อม SHA-256 และตรวจจำนวนแถว รวมการกู้รูปไปยังพื้นที่แยก
- เพิ่ม integration test ที่กู้สำเนาฐานจริงเป็นฐานใหม่ ทดสอบล็อกอิน สิทธิ์ ออกบิล รับชำระ ส่งซ้ำ และ AI ขัดข้อง แล้วลบเฉพาะฐานทดสอบ

## ผลยืนยัน

- MySQL จริงมีตารางหลัก 20 ตาราง เชื่อมต่อและกู้คืนสำเนาได้
- ฐานต้นฉบับมีจำนวนแถวและ checksum เท่าเดิมก่อน–หลัง integration test; ฐานทดสอบถูกลบแล้ว
- หลังบ้าน build ผ่าน; 12 ชุดทดสอบ 214 ข้อผ่าน
- หน้าบ้าน production build ผ่าน; initial bundle 573.72 kB อยู่ใน budget และ 36 ชุดทดสอบ 418 ข้อผ่าน
- AI โหลดโมเดล `best.pt` จริงและผ่าน 5 ข้อทดสอบ: ภาพว่าง ไฟล์ปลอม ขนาดไฟล์ request แบบ chunked และการแยกเลขทศนิยม
- ขั้นตอนฐานข้อมูลจริงผ่าน 11 กลุ่มตรวจ รายละเอียดอยู่ใน `database-test-result.json`

## สิ่งที่ต้องตัดสินใจก่อนเปิดสู่อินเทอร์เน็ต

- ลูกบ้านยังล็อกอินด้วยเบอร์โทรอย่างเดียวตามกฎเดิม หากต้องพิสูจน์เจ้าของเบอร์ต้องออกแบบ OTP/PIN และขั้นตอนช่วยเหลือ
- รูปใน `/uploads/` ยังเข้าผ่าน URL แบบ static หากต้องจำกัดผู้ดูต้องออกแบบสิทธิ์และเปลี่ยนวิธีเสิร์ฟรูป
- ยังไม่มีชุดภาพมิเตอร์จริงพร้อมเลขเฉลย จึงยืนยันการทำงานของโมเดลได้ แต่ยังวัดอัตราความแม่นยำกับสภาพหน้างานไม่ได้
- HTTPS ต้องมีโดเมนและใบรับรองจริง ตอนนี้เตรียมค่ารองรับไว้แล้ว แต่การใช้งานยังเป็น `http://localhost:4200/home`

คู่มือใช้งาน การสำรอง กู้คืน และเตรียม HTTPS อยู่ใน `operations.md`
